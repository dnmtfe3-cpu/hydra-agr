# Hydra Agro — splash animada

Arquivos desta pasta:

- `splash-hydra-agro.html`: prévia isolada da splash, com a animação fornecida.
- `hydra-splash-logo.png`: logo usada na animação (512×512, otimizada para o app).

A prévia funciona sem internet: abra `splash-hydra-agro.html` em um navegador mantendo o PNG na mesma pasta.

Esta branch/PR apenas adiciona o código de referência e o arquivo da logo. Não faz merge nem deploy.
